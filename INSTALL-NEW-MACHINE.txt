D. 加许总你 SSH key 到新机 (让老子能 ssh)
================================================================================

1. 新机本地跑 (需要临时密码):
    sudo apt install -y openssh-server
    sudo systemctl enable ssh
    sudo systemctl start ssh
    mkdir -p ~/.ssh
    chmod 700 ~/.ssh

    # 加许总你的公钥 (从 Mac 拷 ~/.ssh/id_rsa.pub 内容)
    echo "ssh-rsa AAAAB3...mac@..." >> ~/.ssh/authorized_keys
    chmod 600 ~/.ssh/authorized_keys

2. 许总你看新机 IP:
    hostname -I
    ip addr | grep "inet " | grep -v 127.0.0.1

3. 许总你 Mac 加 SSH config:
    cat >> ~/.ssh/config << EOF
    Host new-machine
        HostName <新机IP>
        User <新机用户名>
        IdentityFile ~/.ssh/id_rsa
        IdentitiesOnly yes
        StrictHostKeyChecking no
    EOF

4. 测试 SSH:
    ssh new-machine "whoami; date"
